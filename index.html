欢迎使用 Ann

这是一款专为曲曲机打造的异形气泡生成器。上传气泡素材，调整切割线，一键生成 CSS 代码。

第一步：上传素材

点击上传区域，选择气泡图片。左右气泡可以分别上传，也可以调好一边后翻转到另一边。

第二步：调整切割线

拖动四条红色切割线，保护气泡的四个角不被拉伸。中间区域是拉伸区，气泡变长时只有中间会被拉伸。

第三步：翻转复用

调好一边后，点「翻转复制到另一边」，图片和参数会水平镜像翻转到对侧，省去重复调整。

第四步：复制使用

调整满意后，点击「复制代码」，粘贴到曲曲机的气泡 CSS 设置里即可。代码已适配曲曲机格式。
