欢迎使用 Ann

这是一款专为曲曲机打造的异形气泡生成器。上传你的气泡素材，调整切割线，一键生成可用的 CSS 代码。

第一步：上传素材

点击上传区域，选择你的气泡图片。支持 PNG、JPG、WebP 格式。左右气泡可以分别上传不同素材。

第二步：调整切割线

拖动四条红色切割线，把气泡的四个角保护起来。中间区域是拉伸区，气泡变长时只有中间会被拉伸。

第三步：翻转复用

调好一边的气泡后，点击「翻转复制到另一边」，可以一键水平镜像翻转到对侧，省去重复调整的麻烦。

第四步：复制使用

调整满意后，点击「复制代码」，把生成的 CSS 粘贴到曲曲机的气泡 CSS 设置里即可生效。代码已适配曲曲机格式。
